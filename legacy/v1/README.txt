WELCOME TO THE PULL LIST SORTER 


WHAT IT DOES: 
    - Looks at the PDF pull list from Shipstation
        - NOTE: Needs to be named as expected, and be in the same folder.
    - Gets the text of the SKUs included.
        - Puts them in a csv in ascending order. 


HOW TO USE IT: 
    - First, turn the .command file into a clickable:
        - Terminal, chmod +x START_PullListSorter.command
    - Then click it! 
        - It should try to run, and try to install needed stuff.
    -- IF it is like "Homebrew needed":
        - install homebrew:  `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
        - Then paste whatever the homebrew install says in terminal to set up PATHS.
        -- THEN run it! 
    - It will ask if you want to print.
    - It will save a file with the info!
